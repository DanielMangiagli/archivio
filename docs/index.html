Keep your projects organized from contract to completion.

📁

Project Dashboard

Grid view with search and status filtering. See all your projects at a glance with client, date, and amount info.

🗂️

Project Phases

Organize files by phase: Contract, Execution, Payment. Each with its own structured folder hierarchy.

🖼️

Photo Support

EXIF metadata extraction (camera, date, GPS) and automatic thumbnail generation for project photos.

🔄

Folder Sync

Drop files directly into project folders on disk. Sync detects new and removed files automatically.

📊

HTML Index

Generate a searchable, filterable HTML table of all your projects. Open it in any browser.

🖥️

Cross-Platform

Runs on Windows, macOS, and Linux. Built with Tauri for native performance and small binary size.

How it works

Three steps to a well-organized project.

1

Create a project

Enter the code, name, client, contract date, and amount. The folder structure is created automatically.

2

Add your files

Drag and drop contracts, photos, reports, and invoices into the right phase. Photos get thumbnails automatically.

3

Generate index

Create a searchable HTML overview of all projects. Open it in your browser or share it with your team.
