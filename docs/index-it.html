Come funziona

Tre passi per un progetto ben organizzato.

1

Crea un progetto

Inserisci codice, nome, cliente, data contratto e importo. La struttura delle cartelle viene creata automaticamente.

2

Aggiungi i tuoi file

Trascina contratti, foto, relazioni e fatture nella giusta fase. Le foto ottengono le miniature automaticamente.

3

Genera l'indice

Crea una panoramica HTML cercabile di tutti i progetti. Aprila nel browser o condividila con il tuo team.
